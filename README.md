# FindWrapperTest
Test Project - Wrapper for Find For Use With Github Workflows &amp; Shellcheck. <br>
<p>
<h4> Project Goals: </h4>
<ul>
  <li> streamline the code used by the workflow that calls shellcheck via find | xargs. </li>  
  <li> Make the workflow to be more easily configurable. </li>
  <li> Implement our own custom .shellcheckrc file. </li>
</ul>
</p>

  
<h4> Also includes: </h4>
<ul>
  <li> an example .shellcheckrc file (shellcheckrc-example) </li>  
  <li>a list of known Shellcheck checks (Shellcheck-Checks-README.md / Shellcheck-Checks.list)</li>
</ul>
</p>
